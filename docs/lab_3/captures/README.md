# Вікна VCD для скріншотів звіту ЛР3

Повні записи прогонів (docs/captures/) - десятки секунд з кроком 1 нс, PulseView їх відкриває важко. Тому для кожного скріншота я вирізав коротке вікно навколо події:

```
python3 tools/vcd_window.py <запис> <t0> <t1> <вікно>
```

Час у вікні починається з 0 (= t0). У PulseView: Open -> Import Value Change Dump data, Downsampling factor 100 (10 МГц, крок 0,1 мкс). Канали - D2, D4, D5, D6, D7 (у прогонах `wokwi-cli` немає D0, D1 і D3).

|---|---|---|---|
| `04-estop-6.2.2.vcd` | `6.2.2_2026-11-12_1317.vcd`, 40,230-40,350 | найгірше натискання E-STOP у 6.2.2 (60,5 мс) | D7↑ 15,318; D5↓ 34,200; D7↓ 86,874; D6↑ 94,733 |
| `05-fr03-s2.vcd` | `S2_2026-11-12_1904.vcd`, 45,860-45,930 | найбільша FR-03 від виявлення в S2 (22,6 мс) | D4↑ 20,523; D4↓ 23,664; D2 2000 мкс з 43,138 |
